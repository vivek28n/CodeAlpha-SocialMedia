## 📖 About the Project

PulseAlpha is a responsive full-stack social media application designed to provide an interactive platform for sharing posts, connecting with users, and engaging with a dynamic social feed.

## ✨ Features

- User profiles and social feed
- Create posts with photo attachments
- Hashtag support
- Like and comment functionality
- Animated like interactions
- Follower graph and social interactions
- Responsive interface

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Development Tools:** npm, Git, GitHub

## 🚀 Run Locally

Make sure Node.js and npm are installed.

```bash
cd backend
npm install
npm start
```

Open your browser at:

http://localhost:5001
